# Volunteering Rewards App — Prompt Templates

> Reusable prompt templates for common capstone project tasks.
> Save time by starting from these instead of writing from scratch.

## Templates

### Backend
- `new-api-endpoint.md` — Scaffold a new REST endpoint (route → controller → service → test)
- `new-migration.md` — Create a database migration with rollback
- `debug-api-error.md` — Diagnose a failing API endpoint

### Frontend
- `new-web-screen.md` — Add a new page to the web portal
- `new-mobile-screen.md` — Add a new screen to the mobile app

### Testing
- `run-tests.md` — Run and interpret test results
- `write-unit-test.md` — Write a unit test for a backend module

### Project
- `sprint-update.md` — Update status reports and commit
- `deploy-check.md` — Verify deployment health across all portals

## Usage

```
Start a session with: @prompts/backend/new-api-endpoint.md
Or inline: "Create a new API endpoint following the template in prompts/new-api-endpoint.md"
```
