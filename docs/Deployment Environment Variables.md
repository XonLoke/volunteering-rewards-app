# Production Environment Variables

For Render deployment — set these in Render dashboard or via `render.yaml`:

| Variable | Value | Notes |
|----------|-------|-------|
| `NODE_ENV` | `production` | Enables prod optimizations |
| `PORT` | `3000` | Render sets this automatically |
| `DB_HOST` | _(Render DB host)_ | From Render managed PostgreSQL |
| `DB_PORT` | `5432` | From Render managed PostgreSQL |
| `DB_NAME` | `volunteering_rewards` | From Render managed PostgreSQL |
| `DB_USER` | `postgres` | From Render managed PostgreSQL |
| `DB_PASSWORD` | _(Render DB password)_ | From Render managed PostgreSQL |
| `JWT_ACCESS_SECRET` | _(generate)_ | `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"` |
| `JWT_REFRESH_SECRET` | _(generate)_ | Same command, different value |
| `JWT_ACCESS_EXPIRES_IN` | `15m` | Token lifetime |
| `JWT_REFRESH_EXPIRES_IN` | `7d` | Refresh token lifetime |
| `CORS_ORIGINS` | `https://your-frontend.onrender.com` | Comma-separated |
| `RATE_LIMIT_WINDOW_MS` | `900000` | 15 min window |
| `RATE_LIMIT_MAX` | `100` | Max requests per window |
| `MAX_FILE_SIZE` | `1048576` | 1 MB upload limit |

## Secrets NOT to commit

- `backend/.env` — already in `.gitignore`
- `.env` — root level, also in `.gitignore`
- `JWT_ACCESS_SECRET` — must be unique per deployment
- `JWT_REFRESH_SECRET` — must be unique per deployment
- `DB_PASSWORD` — auto-generated by Render

## Checklist

- [ ] Generate strong JWT secrets (use the crypto command above)
- [ ] Set all env vars in Render dashboard
- [ ] Run database migrations after deploy: `npm run migrate`
- [ ] Run database seed if needed: `npm run seed`
