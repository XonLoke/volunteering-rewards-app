Pulling Files from GitHub

All the team members can pull the files by these command in "command prompt" app:

-------------------------------

git clone https://github.com/XonLoke/volunteering-rewards-app.git
cd volunteering-rewards-app\backend
copy .env.example .env   (edit with their own DB password)
npm install
npm run migrate
npm run seed
npm run dev

-------------------------------

Then open another terminal:

-------------------------------

cd frontend\web_portals
npm install
npm run dev

-------------------------------

And we can access:
