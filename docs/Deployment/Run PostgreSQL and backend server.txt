To run PostgreSQL and backend server:

To run ProgreSQL and create the dbase volunteering_rewards:
"C:\Program Files\PostgreSQL\17\bin\createdb.exe" -U postgres volunteering_rewards

This lists all databases:
"C:\Program Files\PostgreSQL\17\bin\psql.exe" -U postgres -l

A PostgreSQL database is not something you “run” like an app.
You either:
- Connect to it using psql
- Let your backend application connect to it
Start the PostgreSQL service if it is not running.
Since your database already exists, the next step is usually to connect to it.
