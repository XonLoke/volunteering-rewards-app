# Software Functional List — Volunteering Rewards App

> **Version:** 1.0 — 21 May 2026  
> **Source:** Supervisor meeting & workflow analysis

---

## General System — Expected Functions

- Email notifications (approval granted, event reminders, password reset)
- Data export / reports (CSV/PDF download)

---

## 1) Volunteer Mobile App

- Register for volunteering event (organizer issues event QR code)
- Onsite scan QR code for event participation attendance (organizer mobile app scanning the QR code)
- Get reward points from completing volunteering activity
- Options to provide feedback for the participated volunteering events
- Options to give suggestion to the organizers for volunteering events
- Options to feedback to the administrator regarding organizers and events
- Access the point-reward list
- Accumulate points and exchange for selected reward coupon with 6-digit code
- Either choose online or onsite to claim reward
- Provide 6-digit code for redemption of reward (merchant/cashier receives code and verifies with the system)
- View past events history with points breakdown
- Edit own profile / change password
- Push notifications for event

---

## 2) Organizer Web App

- Register as the supplier of volunteering events by providing official approval document
- Add and edit events and associated reward points on calendar for volunteers
- Review and generate report for emailing the completed event
- Review and reply the feedback for completed and non-completed events feedback
- Dashboard with event statistics (total volunteers, completion rate)
- View volunteer attendance reports
- Manage event cancellation / reschedule workflow

---

## 3) Organizer Mobile App

- For scanning participant's QR code as participation attendance
- Award points for volunteer that completed participation

---

## 4) Admin Web App

- Administration of volunteer database
- Administration of organizer database
- Get alarm for the participants that registered and did not turn-up for the events
- Sourcing list of desirable merchants
- Registration for sponsoring merchants
- Provide password for merchant/cashier to login for verifications of the 6-digit code to issue reward
